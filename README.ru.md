# Decky Controller

Плагин для [Decky Loader](https://decky.xyz). Пока он включён, Steam Deck работает как проводной USB‑геймпад
для компьютера, подключённого к порту USB‑C. Поддерживаются два профиля: XInput (совместимый с Xbox 360) и
универсальный HID‑геймпад. В активном режиме встроенный контроллер Deck перехватывается и передаётся на ПК,
экран Deck выключается; режим завершается удержанием заданной комбинации кнопок (по умолчанию L4+R4),
кнопкой в интерфейсе или отключением кабеля. На ПК ничего устанавливать не нужно.

Плагин меняет только состояние ядра в памяти (см. «Что плагин меняет в системе»); перезагрузка возвращает
Deck в исходное состояние.

## Требования

* Steam Deck, SteamOS 3.6 или новее, установленный Decky Loader.
* В BIOS включён режим USB Dual‑Role Device (DRD) — см. ниже, делается один раз.
* Кабель USB‑C с линиями данных. Кабели «только для зарядки» не подходят: ПК не увидит устройство.

### Включение DRD в BIOS

По умолчанию порт USB‑C работает только в режиме хоста (док‑станции, периферия). В режиме DRD порт может
работать и как устройство, если подключён к компьютеру; при подключении док‑станции или периферии он
по‑прежнему работает как хост — роль выбирается автоматически по подключённому устройству.

1. Полностью выключите Deck.
2. Удерживая Volume Up, нажмите Power; после звукового сигнала отпустите обе кнопки — откроется меню BIOS.
3. Выберите **Setup Utility**.
4. Откройте **Advanced → USB Configuration → USB Dual‑Role Device**.
5. Измените значение с **XHCI** на **DRD**.
6. Сохраните изменения и выйдите (**Exit → Exit Saving Changes** или F10). Deck перезагрузится.

Те же шаги показывает кнопка **How to enable DRD** в плагине.

## Установка

Три способа:

* **Из магазина Decky Plugins Extended** — магазин сообщества, объединяющий официальный каталог с
  плагинами, которых в нём нет. В Decky откройте **Settings → General → Store Channel**, выберите
  `Custom` и укажите в **Custom Store** адрес `https://decky-extended-plugins.beallio.com/plugins.json`.
  После этого установите **Decky Controller** из магазина Decky как обычно; обновления приходят туда же.
* **По ссылке** — включите **Decky → Settings → Developer mode**, затем **Decky → Developer → Install
  Plugin from URL**, вставьте
  `https://github.com/flexlug/decky-controller/releases/latest/download/decky-controller.zip`.
* **Из файла** — скачайте `decky-controller.zip` по той же ссылке, скопируйте на Deck (SD‑карта, флешка,
  `scp`) и выберите **Decky → Developer → Install Plugin from ZIP** (нужен Developer mode).

Плагин появится в меню быстрого доступа на вкладке Decky.

### Почему плагина нет в официальном магазине Decky

Правила подачи в официальную базу плагинов требуют, чтобы бо́льшая часть кода не была написана генеративным
ИИ. Код этого плагина написан с помощью ИИ‑агентов (с ревью и проверкой человеком на реальном устройстве),
поэтому в официальный магазин он не подаётся — вместо этого он доступен в магазине
[Decky Plugins Extended](https://github.com/beallio/decky-plugins-extended). Остальные технические
требования официального магазина соблюдены.

## Использование

1. Подключите Deck к ПК кабелем USB‑C. Док‑станция должна быть отключена: порт работает либо как хост, либо
   как устройство.
2. Откройте меню быстрого доступа (кнопка …) → **Decky Controller**. Раздел **Status** показывает:
   **DRD** — включён ли режим в BIOS; **Cable** — что порт видит в данный момент (**PC**, **Charger**,
   **Dock**, **Not connected**, **Unknown**); **Controller** — состояние встроенного контроллера;
   **Mode** — состояние сессии. После включения режима строка **Cable** заменяется на **Host**: **Waiting…**
   до того, как ПК опознает устройство, затем **Connected**.
3. Включите переключатель **Controller mode**. Встроенный контроллер перехватывается, экран выключается, ПК
   обнаруживает новый контроллер в течение нескольких секунд. Проверить можно в `joy.cpl` (Windows) или в
   любой игре.
4. Для выхода: удерживайте комбинацию выхода 1,5 с (по умолчанию L4+R4); либо коснитесь экрана (он
   включится на несколько секунд) и нажмите **Stop controller mode** в оверлее; либо отключите кабель. Экран включится,
   контроллер вернётся Steam.

В активном режиме Deck не реагирует на свои кнопки, включая Steam и QAM: весь ввод уходит на ПК.

### Профили

| Профиль | Что видит ПК | Назначение |
|---|---|---|
| **XInput** (Xbox 360) — по умолчанию | проводной XInput‑контроллер (VID 045E / PID 028E); в Windows работает стандартный драйвер `xusb22.sys`, в Linux — `xpad` | игры под Windows, эмуляторы, любое ПО с поддержкой XInput |
| **Generic HID** | USB HID‑геймпад: 6 осей, hat, 16 кнопок | Linux, ПО только с DirectInput, запасной вариант |

Раскладка XInput: A/B/X/Y → A/B/X/Y, L1/R1 → LB/RB, L2/R2 → триггеры, стики → стики, L3/R3, View → Back,
Menu → Start, D‑pad → D‑pad. Кнопки Steam и QAM не передаются. Задние кнопки L4/L5/R4/R5 по умолчанию не
назначены; назначение задаётся в разделе **Back paddles**. Комбинация выхода на ПК не передаётся.

### Настройки

* **Profile** — XInput (Xbox 360) или Generic HID.
* **Kill switch** — комбинация выхода: L4+R4, L5+R5, L4+L5+R4+R5 или Steam+QAM; удержание 1,5 с. Время
  удержания в интерфейсе не настраивается; при необходимости измените `kill_hold_ms` в
  `~/homebrew/settings/decky-controller/settings.json`.
* **Turn screen off while active** — выключать экран на время сессии. В игровом режиме панель выключается
  через gamescope; в Desktop Mode используется DPMS KDE, если доступен, иначе снижается яркость подсветки.
  Касание экрана включает его на несколько секунд.
* **Back paddles** — что отправляют на ПК L4/L5/R4/R5: A/B/X/Y, LB/RB, L3/R3, View/Menu, направления
  D‑pad или ничего.

## Ограничения

* Порт USB‑C в активном режиме занят соединением с ПК: док‑станции, хабы, Ethernet‑адаптеры и другие
  USB‑устройства использовать нельзя (их подключение переводит порт обратно в режим хоста). Зарядка идёт
  от USB‑порта ПК в пределах его возможностей.
* Интерфейс Deck в активном режиме недоступен, включая кнопку Steam.
* Гироскоп, трекпады, вибрация и Bluetooth в текущей версии не поддерживаются.
* Если на Deck вторым разделом установлена Windows: при включённом DRD она не видит порт USB (у Windows нет
  драйвера для dual‑role‑контроллера); для USB под Windows верните в BIOS значение XHCI. SteamOS работает в
  обоих режимах.

## Устранение неполадок

* **DRD: Disabled** — выполните шаги раздела «Включение DRD в BIOS». После включения строка показывает
  **Enabled** сразу после загрузки SteamOS.
* **Cable: Not connected** при подключённом кабеле — порт не видит питания: неисправен кабель или порт, либо
  порт ПК в спящем режиме. Попробуйте другой кабель с линиями данных или другой порт; некоторым ПК нужна
  секунда после подключения. **Charger** — подключено зарядное устройство, а не ПК. **Dock** — подключена
  док‑станция или периферия, отключите её. **Unknown** — данные ещё не прочитаны; откройте панель повторно.
* **Режим не запускается или ПК не видит устройство** — нажмите **Stop (full reset)**, переподключите
  кабель, повторите.
* **Встроенный контроллер не работает после сбоя** — нажмите **Stop (full reset)** (сенсорный экран работает
  всегда) или перезагрузите Deck: изменения хранятся только в памяти ядра.
* **Журналы** — **Decky → Settings → Developer → Show plugin logs** либо файлы в
  `~/homebrew/logs/decky-controller/`. Кнопка **Diagnostics** в панели выводит состояние и последние 50
  строк журнала демона.

## Что плагин меняет в системе

На время сессии плагин: отвязывает встроенный контроллер от драйвера `usbhid`; создаёт USB‑гаджет на порту
USB‑C через интерфейсы ядра `raw_gadget` или `configfs`; выключает дисплей (gamescope, KDE DPMS или
подсветка). Всё это — состояние ядра в оперативной памяти. Корневая файловая система (только для чтения),
загрузчик, EFI‑раздел и BIOS не изменяются. Единственная постоянная настройка — переключатель DRD в BIOS,
который пользователь меняет сам. Изменения откатываются при завершении сессии, остановке или выгрузке
плагина; в крайнем случае их снимает перезагрузка.
